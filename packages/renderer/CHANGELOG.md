# @svelte-pdf/renderer

## 0.1.0

Initial release. Svelte 5 component layer for svelte-pdf: `Document`, `Page`, `View`, `Text`, `Link`, `Note`, `Image`, browser components `PDFViewer` / `PDFDownloadLink`, the `usePDF()` hook, the `Font` API, and server APIs `renderToBuffer` / `renderToStream` / `renderToFile`.
